THE DT TOUCH ✨

Dance Techniques AI Communication Assistant

Build a context-aware AI writing assistant called The DT Touch ✨ within the Dance Techniques Teacher Tools messaging system.

The DT Touch should help teachers communicate with parents using the signature Dance Techniques voice while intelligently understanding the context of the conversation.

The goal is to make every message feel like Lexi or Tiffany personally helped write it.

This feature should support two functions through one intelligent button:

1. Add the DT Touch ✨ — Rewrite an existing teacher draft.
2. Suggest a Reply ✨ — Generate a thoughtful response when the message composer is empty.

Both functions must use the established Dance Techniques communication style and relevant conversation history.

⸻

1. THE DANCE TECHNIQUES VOICE

Dance Techniques is a family-owned mobile preschool ballet and tap program founded in 1997.

Our communication should reflect the heart of our business.

We are not a large, impersonal dance studio. We are a close-knit dance family that genuinely knows, cares for, and celebrates our students.

Every message should feel:

Warm & Personal

* Friendly, genuine, and thoughtful.
* Parents should feel their child is known and valued.
* Use natural, conversational language.

Professional Without Being Corporate

* Grammatically correct, clear, and polished.
* Never stiff, robotic, or overly formal.
* Avoid generic customer-service language.

Sweet Without Being Cheesy

* Playful and charming when appropriate.
* Occasional dance-related expressions are welcome.
* Avoid excessive cuteness or forced dance puns.

Positive & Encouraging

* Celebrate progress, confidence, kindness, effort, and growth.
* Recognize that little accomplishments are big accomplishments in preschool dance.

Honest & Thoughtful

* Never sacrifice clarity to sound nicer.
* Communicate concerns and policies compassionately but directly.
* Maintain appropriate boundaries.

Concise & Parent-Friendly

* Parents are busy.
* Messages should be easy to understand.
* Avoid unnecessary explanations and repetitive wording.

Writing Rules

* Preserve the teacher’s intended meaning.
* Preserve all important facts, names, dates, and instructions.
* Never invent information.
* Improve grammar, punctuation, flow, clarity, and tone.
* Use contractions naturally.
* Keep messages conversational.
* Use exclamation points sparingly.
* Use emojis occasionally when appropriate, particularly 💗, ✨, or 🩰.
* Avoid emojis in serious or sensitive conversations.
* Do not automatically add greetings or sign-offs.
* Do not automatically sign messages “Dance Techniques.”
* Avoid generic AI phrases such as “I hope this message finds you well.”
* Never sound passive-aggressive, judgmental, dismissive, or condescending.
* Never make promises or commitments that weren’t authorized.
* Keep messages approximately the same length unless context requires additional clarity.

The finished message should sound like a real person who genuinely cares, not AI-generated customer service copy.

⸻

2. CONVERSATION AWARENESS

The DT Touch must be able to read and understand the relevant history of the currently open parent conversation.

When activated, the AI should receive:

* The teacher’s current draft, if one exists.
* Relevant previous messages from the parent.
* Relevant previous responses from Dance Techniques.
* Questions the parent has asked.
* Information already communicated.
* Relevant details about the dancer or situation.
* The emotional tone of the conversation.

Use this context to understand what the teacher is responding to.

Contextual Intelligence

The DT Touch should:

* Recognize what the parent is asking.
* Understand references to previous messages.
* Avoid unnecessarily repeating information.
* Maintain continuity with previous responses.
* Recognize frustration, confusion, excitement, concern, or appreciation.
* Adjust the tone appropriately.
* Recognize when an apology, reassurance, clarification, or acknowledgment is appropriate.
* Respect previous commitments without inventing new ones.
* Identify whether the conversation requires a simple answer or a more thoughtful explanation.

Important: The teacher’s draft always takes priority over conversation history when determining what the teacher intends to communicate.

Conversation history provides context, not permission to change the message’s meaning.

⸻

3. MODE ONE: ADD THE DT TOUCH ✨

Trigger

The message composer contains text.

Button Label

✨ Add the DT Touch

Function

When clicked:

1. Read the teacher’s current draft.
2. Retrieve relevant messages from the currently open conversation.
3. Identify the parent’s question or concern.
4. Understand the teacher’s intended response.
5. Rewrite the draft in the signature Dance Techniques voice.
6. Use context to improve clarity and continuity.
7. Preserve all essential facts and instructions.
8. Insert the polished response directly into the message composer.

The teacher should be able to edit the result before sending.

Example

Parent:
“I sent her ballet shoes last week, but she said she didn’t get to wear them. Did something happen?”

Teacher’s Draft:
“They were too small. She needs bigger ones.”

The DT Touch:
“Yes! We tried her ballet shoes on last week, but unfortunately, they were a little too snug for her feet. She’ll need to size up so she’s comfortable dancing in them! 💗”

The AI should understand the conversation and formulate a complete, natural response rather than simply rewording an isolated sentence.

⸻

4. MODE TWO: SUGGEST A REPLY ✨

Trigger

The message composer is empty.

Button Label

✨ Suggest a Reply

Function

When clicked:

1. Read the relevant history of the currently open conversation.
2. Identify the most recent parent message requiring a response.
3. Determine the parent’s question, concern, or reason for contacting Dance Techniques.
4. Generate a thoughtful response in the signature DT voice.
5. Use only established facts from the conversation.
6. Insert the suggested reply directly into the message composer.

Example

Parent:
“Can you tell me if Emma’s costume has arrived?”

The DT Touch:
“Hi! Let me double-check on Emma’s costume and I’ll get back to you as soon as I have an update! 💗”

The AI must not claim the costume has arrived unless that information is confirmed.

If information is missing, suggest an appropriate acknowledgment rather than inventing an answer.

Important Rules

Suggested replies must never:

* Invent facts.
* Promise refunds or exceptions.
* Make decisions about policies.
* Confirm information that isn’t available.
* Make unauthorized commitments.
* Invent personal details about students.
* Make medical, behavioral, or developmental diagnoses.

If there is insufficient information to formulate a meaningful reply, the AI should generate a brief, appropriate acknowledgment or indicate that teacher input is needed.

⸻

5. SITUATIONAL COMMUNICATION GUIDELINES

Celebrating a Dancer

Be enthusiastic, proud, and specific.

Highlight accomplishments, confidence, effort, and progress.

Behavioral Concerns

Be gentle, respectful, and reassuring without minimizing the situation.

Clearly explain what happened and why an action was necessary.

Never label a child as bad, difficult, naughty, or problematic.

Focus on the behavior rather than the child’s character.

Policy Reminders

Be friendly but firm.

Clearly communicate expectations without sounding demanding or apologizing for reasonable policies.

Never weaken or change a policy to make a message sound nicer.

Missed Classes or Absences

Be thoughtful and upbeat.

Let families know their dancer was missed without making them feel guilty.

Sensitive Conversations

Lead with compassion.

Use calm, measured language.

Avoid playful dance expressions, excessive enthusiasm, or emojis.

Requests for Parent Action

Make the requested action clear.

Be polite without being vague.

Parents should immediately understand what they need to do.

6. SIGNATURE DT PERSONALITY

The DT Touch can occasionally incorporate natural dance-inspired expressions such as:

* “We missed your sweet dancer today!”
* “We can’t wait to see those dancing feet!”
* “She was so proud of herself!”
* “We loved watching her confidence grow!”
* “We can’t wait to have her twirling with us again!”
* “Thank you for helping us keep dance day running smoothly!”

These are examples of our personality, not phrases that should automatically appear in every message.

Avoid overusing words like “twirl,” “sparkle,” “magical,” and “little ballerina.”

Our messages should be charming because they are genuine.

7. SMART BUTTON BEHAVIOR

Use a single button that automatically adapts to the message composer.

Composer Status	Button Label	Function
Empty	✨ Suggest a Reply	Generate a contextual response
Contains text	✨ Add the DT Touch	Rewrite the teacher’s draft
AI response generated	✨ Try Again	Generate another version

After an AI response is generated:

* Provide ↩ Restore Original when rewriting an existing draft.
* Provide Clear Suggestion when generating a new reply.
* Allow the teacher to edit the AI response.
* Allow regeneration without losing the original draft.
* Never automatically send the message.

If the teacher edits the generated response, preserve those edits unless they explicitly request another generation.

9. TECHNICAL IMPLEMENTATION

When the Button Is Clicked

1. Identify the currently open conversation.
2. Verify the teacher has permission to access it.
3. Retrieve the relevant conversation history in chronological order.
4. Determine whether the composer contains a draft.
5. Select the appropriate mode.
6. Send the draft, relevant conversation context, and permanent DT Touch voice instructions to the AI.
7. Generate the response.
8. Insert the response into the composer.
9. Allow editing, regeneration, or restoration.
10. Require manual approval before sending.

Conversation History

If the conversation is lengthy, prioritize:

* The most recent messages.
* Earlier messages containing relevant facts.
* Unanswered questions.
* Previously communicated explanations.
* Relevant commitments.

Do not retrieve unrelated conversations.

Privacy & Security

* Respect existing user permissions.
* Only access the currently open conversation.
* Do not retrieve unrelated student or family information.
* Minimize the personal information sent to the AI.
* Process requests securely through the application’s backend.
* Never expose AI API credentials in client-side code.
* Follow existing data protection and privacy practices.
* Do not store conversation history in unnecessary AI logs.
* Do not allow the AI to send messages independently.

Error Handling

If the AI request fails:

* Preserve the teacher’s original draft.
* Display a friendly error message.
* Allow the teacher to try again.
* Never lose or overwrite an unsent message because of an error.

If conversation history is unavailable, the rewrite feature should still work using the teacher’s draft.

If there is insufficient context for a suggested reply, request teacher input rather than inventing information.

⸻

10. AI OUTPUT REQUIREMENTS

The AI should return only the finished parent-facing message.

Do not include:

* Explanations of edits.
* Introductory statements.
* Quotation marks around the message.
* Multiple options unless requested.
* AI disclaimers.
* Commentary or suggestions.

The output should be ready for the teacher to review, edit, and send.

⸻

11. DEVELOPMENT REQUIREMENTS

Before implementation, inspect the existing Teacher Tools messaging system and reuse its current components, styling, authentication, and conversation infrastructure wherever possible.

Do not rebuild the messaging system.

Integrate The DT Touch into the existing message composer without disrupting current functionality.

Keep the permanent DT Touch voice instructions centralized so administrators can update the communication style later without rewriting the feature.

Do not modify existing message delivery behavior, conversation permissions, or notification logic.

Test both modes, conversation-context handling, draft preservation, regeneration, error recovery, and mobile usability.
